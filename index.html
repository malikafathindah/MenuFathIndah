Panduan Migrasi ke Supabase

  1. Buka dashboard Supabase Anda di supabase.com dan buat project baru.
  2. Klik menu SQL Editor di dashboard Supabase.
  3. Unduh skema SQL menggunakan tombol Unduh Skema SQL Supabase di atas, lalu salin dan jalankan di SQL Editor Supabase. Skema ini sudah mencakup pembuatan tabel users, activity_logs, serta data awal (seed).
  4. Salin Project URL dan Anon Key dari menu Project Settings -> API ke form pengaturan di atas.
  5. Klik tombol kartu Supabase (PostgreSQL) untuk mengalihkan sistem secara langsung!

Konfigurasi Auto-Upload Berkas Brosur

Folder Target Penyimpanan Berkas

Agar file lokal langsung tersimpan secara otomatis, gunakan Webhook Apps Script. File yang diunggah akan otomatis memiliki link publik dan tercatat di database!
Cara Pasang Webhook Auto-Upload (Hanya 1 Menit)
  1. Buka script.google.com dengan akun pemilik folder Brosur.
  2. Klik New project (Proyek baru), beri nama Uploader Brosur Fath Indah.
  3. Tempel skrip berikut lalu klik Save.
  4. Klik Deploy (Terapkan) -> New deployment (Penerapan baru).
  5. Pilih tipe Web app (Aplikasi web). Atur:
    • Execute as: Me (email anda)
    • Who has access: Anyone (Siapa saja)
  6. Klik Deploy, berikan otorisasi izin Drive, lalu salin URL Web App dan tempel pada form ini!
